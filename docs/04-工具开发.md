# 工具开发

工具（tool）是 AI 模型可以调用的函数，是 DSH 插件最常见的形态。注册工具的唯一正确方式是 `ctx.tools.register(defineTool(...))`。

## 最小完整示例

```ts
import type { Context } from '@deepseek-ai/cordis'
import { defineTool } from '@deepseek-ai/dsh-tools'

export const name = 'my-tool'              // 插件 id，必须与 patch 文件的行 id 一致
export const inject = ['tools']            // 必需：让 ctx.tools 可用

export function apply(ctx: Context) {
  ctx.tools.register(
    defineTool({
      name: 'get_weather',                 // 模型调用的工具名（snake_case）
      description: 'Get current weather for a city.',  // 模型决定何时调用的依据
      parameters: {                        // 输入 JSON Schema DSL（对象）
        city: { type: 'string', description: 'City name', required: true },
      },
      output: {                            // 必需，没有默认值
        schema: {
          type: 'object',
          properties: {
            temperature: { type: 'number', required: true },
            condition: { type: 'string', required: true },
          },
          additionalProperties: false,     // 对象 schema 必须显式声明
        },
        render: (_args, value) => [{ type: 'text', text: `${value.temperature}°C, ${value.condition}` }],
      },
      async execute(args) {                // 注意是 execute，不是 run
        return { temperature: 22, condition: 'sunny' }
      },
    }),
  )
}
```

## schema DSL 硬规则

| 规则 | 说明 |
|---|---|
| `required` 是属性内联的 | 每个属性里写 `required: true`。**没有** `required` 数组，**没有** `required: false`，用了会破坏类型推断 |
| `additionalProperties` | 每个对象 schema 必须显式设置（`false` 禁止多余键；隐式参数根保持开放） |
| `output` 必填 | 没有 `output` 无法通过类型检查。必须含 `schema`（对象 schema）+ `render(args, value)` 返回 `ContentBlock[]` |
| render 块 | 返回 `{ type: 'text', text: string }` 项（`ContentBlock` 类型来自 `@deepseek-ai/dsh-llm`） |
| `execute(args)` | 直接返回 JS 对象/字符串（canonical value）；不是 `run`，没有 harness 专用第二参，除非需要执行上下文（`execute(args, exec)`） |
| 可选参数 | 直接省略 `required` 字段 |
| 枚举约束 | 字符串参数用 `enum: ['a', 'b']` 约束取值，让类型推断精确 |

`parameters` 与 `output.schema` 是同一套 value-schema DSL 的两个面：`parameters` 是隐式开放对象根、必填用属性内联；`output.schema` 声明 canonical 返回值，注册时被 `assertSupportedJsonSchema` 强制校验。

## execute 契约

- **参数已替你校验**：`defineTool` 在 `execute` 运行前按 schema 校验模型生成的 `arguments`（类型、必填键、字面量约束、oneOf、嵌套值）。`execute` 内部拿到的 `args` 与 `InferArgs` 一致。DSL 表达不了的约束（非空字符串、正数、跨字段规则）仍需自己检查。
- **返回一个 canonical JSON 值**：`execute` 只返回推断出的值，注册表把它快照为无损 JSON、校验、冻结，再传给 `output.render(args, value)`。不要在返回值里塞 content block，不要让调用方从散文里解析 id 和字段。
- **抛错或返回非法值 = isError**：基础设施失败就 throw；业务上的非理想状态（如非零退出码）用 canonical value 表达，让 render 解释。
- **尊重 `exec.signal`**：信号触发时取消在途工作。
- **`exec.agent` 是调用者 Agent**：`agent.session.header.cwd` 是工作区，`agent.session` 是可 append 事件的会话，`agent.id` 是会话 id。子代理编排（`subagents.startContinuable` 等）要求传 `parent: exec.agent`。异步通知用 `agent.inject({ content, source: { kind: 'plugin', plugin: '<name>' } })`——它追加到**下一次**模型请求，不是唤醒。
- **注册借用只读定义**：注册后不要修改 schema 或替换回调。要热替换工具，dispose 其 effect 再注册新的。

## 长任务与后台作业

需要 `run_in_background` 时用 `ctx.jobs.start({ kind, label, owner: exec.agent, run })` 注册后台作业，成功分支返回类型化句柄如 `{ kind: 'background', jobId }`。PTC 模式绝不能从散文里解析 jobId。前台工作仍耦合 `exec.signal`；后台作业发布后用任务自有的取消信号，`job_kill` / owner 销毁 / 服务 teardown 拥有其生命周期。

## UI 卡片（可选）

`output.render` 返回模型可见内容；UI 卡片是另一回事，通过纯展示投影声明：

- `presentCall(args)` → 待处理卡片：`{ card: 'generic', ... }`、`{ card: 'terminal', ... }`（你的调用就是 shell 命令）、`{ card: 'diff', diffs, ... }`（创建/修改文件）。
- `presentResult(args, { content, isError, meta? })` → 完成卡片：generic / terminal / diff / read / search / web。
- `output.presentationMeta(args, value)` 从同一 canonical value 派生可重放的 JSON，持久化在 `tool/result` 的 `result.meta` 上，让卡片在重放时存活。

硬规则：这些函数在实时流和会话日志重放上都会运行，必须是 `args`（+ result）的纯函数——**不能有 I/O、不能读会话状态、不能读时钟/随机数**。UI 专用格式（```console 块、diff、相对路径）不要塞进 canonical value 或 Native 内容。

## 常见错误

| 错误 | 修复 |
|---|---|
| 用 `ctx.tools.register('name', { run(...) })` 或对象 map | API 是 `ctx.tools.register(defineTool({ name, description, parameters, output, execute }))`，每个工具一个对象，`execute` 不是 `run` |
| 忘记 `export const inject = ['tools']` | 没有它 `ctx.tools` 运行时是 `undefined`，插件崩溃报 "no service available" |
| 漏掉 `output` | 类型检查不过，`defineTool` 要求它 |
| `required: ['city']` 数组或 `required: false` | 只用属性内联 `required: true` |
| 对象 schema 没有 `additionalProperties` | 显式加 `additionalProperties: false` |
| 从 `koishi` / `@koishijs/...` 导入 | dsh 用 `@deepseek-ai/cordis`，类型来自 `@deepseek-ai/dsh-tools` |
| patch 的 `id` 与 `export const name` 不一致 | 工具静默不注册 |
| 注册了工具但模型从不调用 | 检查 `description` 是否写清了何时用、怎么用 |
